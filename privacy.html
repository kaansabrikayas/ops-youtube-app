Privacy Policy: Ops YouTube Uploader

Last updated: October 18, 2026

Who uses this app

Ops YouTube Uploader is a personal tool used only by its owner to manage their own YouTube channels. It is not offered to other people.

What data it accesses

With the owner's consent through Google sign-in, the app uses the YouTube Data API and the YouTube Analytics API to upload and schedule videos, edit video and channel details, and read view and audience statistics of the owner's own channels. It does not access any other user's data.

How data is stored

Sign-in tokens and statistics are stored only on the owner's own computer. Nothing is sent to any server other than Google's APIs.

Sharing

No data is sold, shared or transferred to anyone. No data is used for advertising.

Google API Services

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Uses of YouTube data are also subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
